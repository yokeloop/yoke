## A workflow, not a toolbox

`yoke` is a Claude Code plugin. It ships a short loop that turns a ticket into a pull request — without losing context between steps. Discuss the plan, hand it to `/yoke:do`, review the PR on GitHub, then `/yoke:merge`.

<CardGrid>
  <Card title="Flow" icon="rocket">
    `/yoke:bootstrap` prepares the project once. `/yoke:grill` (or
    `/yoke:grill-docs`) stress-tests the plan. `/yoke:do` executes and opens the
    PR. `/yoke:merge` runs the post-PR tail after you approve.
  </Card>

<Card title="Spec" icon="open-book">
  `/yoke:prd` turns a conversation into a PRD issue. `/yoke:issues` breaks it into tracer-bullet sub-tasks in dependency
  order — hand a URL to `/yoke:do`.
</Card>

<Card title="Git" icon="github">
  `/yoke:gca` commits with smart grouping. `/yoke:gp` pushes with checks. `/yoke:pr` creates or updates a pull request.
  `/yoke:do` folds all three into its finish.
</Card>

<Card title="Utilities" icon="setting">
  `/yoke:review` finds and fixes problems. `/yoke:journal` saves session memory. `/yoke:handoff` compacts the
  conversation. `/yoke:help` explains the rest.
</Card>

  <Card title="Plugin dev" icon="puzzle">
    `/sync-docs` regenerates this very catalog from `skills/*/SKILL.md`. One
    source of truth for README, CLAUDE.md, and this site.
  </Card>
</CardGrid>
